# PrestoKit
A simple CSS toolkit for simple styling.

PrestoKit is a prebuilt stylesheet thats built off [csstools' updated version](https://github.com/csstools/normalize.css) of [normalize.css](https://github.com/necolas/normalize.css), made by [Nicolas Gallagher](https://github.com/necolas/).

---

Features:
 - Simple horizontal div centering
 - Light and dark styling defaults
 - Common page formatting utilities
 - Ready-to-use CSS
 - Standardized and easy to read page setup
